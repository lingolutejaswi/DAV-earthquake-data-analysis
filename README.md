# Earthquake Data Analysis – Excel Project

## Project Overview
This project analyzes an earthquake dataset containing 1,000 records and 19 columns. The analysis was performed in Microsoft Excel using the dataset and focuses on earthquake magnitude, depth, significance, intensity, magnitude type, alert level, and yearly trends.

## Dataset
- **Records:** 1,000
- **Columns:** 19
- **Date range:** 1995-05-05 to 2023-08-16
- **Source file:** `TASK.csv`

## Analysis Completed in Excel

### 1. Magnitude Analysis
- Analyzed earthquake magnitude using the `magnitude` column.
- Compared earthquake records across magnitude ranges.
- Identified the distribution of earthquakes by magnitude band.

### 2. Depth Analysis
- Examined earthquake depth using the `depth` column.
- Used the depth values to understand how shallow and deep earthquakes are distributed.

### 3. Significance and Intensity
- Analyzed earthquake significance (`sig`).
- Examined Modified Mercalli Intensity (MMI) values (`mmi`).

### 4. Magnitude Type
- Counted and compared the different magnitude types using `magType`.

### 5. Alert Level
- Analyzed earthquake alert levels using `alert`.

### 6. Yearly Trend
- Examined the number of significant earthquakes by year to identify changes and trends over time.
